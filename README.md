# 小红书笔记助手

面向 **macOS / Apple Silicon + 腾讯应用宝 Mac 版** 的独立桌面工具。输入小红书官方短链或笔记长链，通过应用宝中的安卓小红书处理笔记。

当前版本 **v0.2.0**：[下载最新版](https://github.com/Starlight-bananice/xhs-note-toolkit/releases/latest)。新版采用浅色工作区、深色侧栏和专属应用图标，左下角固定显示版本号与更新按钮。

## 功能

- 修复链接：打开目标笔记，操作安卓客户端的分享面板，取得真正的“复制链接”结果。
- 支持图文、视频的不同分享入口。打开分享面板后优先直接调用“复制链接”控件，即使按钮尚未显示；客户端没有暴露该控件时，才在安卓内部横向滚动查找。
- 可选抓取作者、点赞、收藏、评论；每个字段可单独勾选。
- 取消修复和抓取数据后，仅检查笔记是否失效。
- 客户端显示“当前内容无法展示”时，按本工具约定记录为“已删除”，说明列保留原提示。
- 批量处理、按笔记去重、停止、继续未完成条目、自动保存 Excel。
- 保留安卓分享原链、展开后的链接和原始分享文案，保留全部分享参数，不伪造凭证。

## 使用

1. 安装腾讯应用宝 Mac 版，在其中安装并打开小红书，完成登录。
2. 打开“小红书笔记助手.app”。粘贴官方短链、长链，或含链接的分享文案。
3. 勾选本次需要的修复和抓取项目；仅检查有效性可直接点击对应按钮。
4. 如需修改保存位置，展开“连接与保存设置”，选择 Excel 文件夹。
5. 点击“开始处理”。结束或停止后自动保存已取得的结果；也可手动导出。

运行时保持应用宝内的小红书开启，让工具独占该安卓窗口。软件不控制 Mac 鼠标，但会切换安卓页面、触发安卓触摸操作，并使用客户端同步到 Mac 的剪贴板。不要同时手动操作这个小红书窗口，以免切换到其他笔记。

应用宝的设备、窗口显示器及自带 `adb` 默认自动识别。只有多个设备或安装位置特殊时，才需要在连接设置中填写设备编号或选择 `adb`。不会读取其他安卓应用。

## 结果说明

| 状态 | 含义 |
| --- | --- |
| 完成 | 已取得安卓分享链接，并核对目标笔记一致 |
| 可访问 | 已确认笔记详情可以读取；本次未要求修复链接 |
| 部分完成 | 笔记可以打开，但部分选定字段没有读取到 |
| 已删除 | 客户端显示“当前内容无法展示”等约定失效提示；原文保留在说明列 |
| 待核验 | 已取得安卓分享原链，但网络展开未完成，尚未确认链接目标 |
| 访问受限 / 需验证 | 客户端要求登录、验证或提示限制，停止批次，留待人工处理 |
| 处理失败 | 打开、读取、复制或链接归属核对失败；不据此判为删除 |

空白字段表示未取得；真正的 `0` 保留为 `0`。客户端只显示“1.2万”时保留显示值，不虚构精确计数。Excel 中的分享链接包含客户端提供的凭证，请按需要分享结果文件。

每篇笔记完成后暂存在当前用户的 `~/Library/Application Support/XHSNoteToolkit/session.json`，便于退出后继续处理。运行数据、测试链接、截图和导出的结果不进入源码仓库。

## 软件更新

启动时自动检查 GitHub 最新正式版；也可点击左下角“检查更新”。发现新版后按钮显示目标版本，点击后下载、校验、安装并重新打开软件，恢复输入、处理选项和结果。正在处理笔记时不能安装更新。

检查失败会显示“重试检查”及原因，不会误报为最新版。也可点击旁边的外链按钮到正式版下载页手动下载安装。0.1.0 没有应用内更新入口，需要先手动安装 0.2.0。

后续发布请使用 `v主版本.次版本.修订号` 标签，并上传对应的 `XHSNoteToolkit-版本号-macOS-arm64.zip`。更新器只接受本项目的正式 Release、匹配的安装包、GitHub SHA-256 下载校验及正确的应用身份和版本；草稿与预发布版不作为正式更新。

## 构建

需要 Apple Silicon Mac、macOS 13 或更新版本，以及 Xcode Command Line Tools：

```sh
./build.command
./dist/小红书笔记助手.app/Contents/MacOS/XHSNoteToolkit --self-test
```

构建产物是 `dist/小红书笔记助手.app`。采用本地临时签名，未经过 Apple 公证。第一次打开如被系统阻止，可在系统“隐私与安全性”中对该应用选择“仍要打开”。

`Resources/toolkit-bridge.dex` 是仓库内 `AndroidBridge/ToolkitBridge.java` 的编译产物。它以安卓现有 shell 身份临时运行，读取小红书的控件；支持应用宝的独立安卓显示窗口，不安装 APK、不需要 root、不变更权限。批次结束关闭会话并清理本次临时文件。

重新编译安卓组件需要 JDK 17 和 [Android 官方 R8/D8](https://r8.googlesource.com/r8/+/refs/heads/main/README.md)：

```sh
TOOLKIT_JAVA_HOME=/path/to/jdk17 ./build_bridge.command
```

开发验证也可通过命令行运行；真实数据不会随源码分发：

```sh
./dist/小红书笔记助手.app/Contents/MacOS/XHSNoteToolkit --batch links.txt --output result.json --xlsx result.xlsx
# 仅检查有效性：增加 --status-only
# 只抓取数据、跳过分享修复：增加 --no-repair
```

独立项目复用了作者原“小红书链接修复”工具的链接校验思路和 Excel 封装实现。两个原工具不作为本软件的运行依赖。

应用图标的矢量绘制源码为 `scripts/render_icon.swift`；构建时直接生成 PNG、完整尺寸图标集与 ICNS，无需额外图像依赖。
